# 3D 资源来源与许可证

这些模型随前端本地分发，不在运行时请求第三方模型站。

## farm-helper.glb

- 来源：Gobkit Free 3D Assets，`minion/minion-a01.glb`
- 原始地址：https://github.com/Ariescar/gobkit-free-assets
- 许可证：CC0 1.0 Universal（公共领域）
- 用途：游戏模式中可控制的低多边形农场助手；项目为其添加了程序化草帽。

## garden-fox.glb

- 来源：Khronos glTF Sample Assets，`Models/Fox/glTF-Binary/Fox.glb`
- 原始地址：https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox
- 原模型：PixelMannen，CC0 1.0 Universal。
- 绑定与动画：tomkranis，CC BY 4.0 International。
- glTF 转换：AsoboStudio 与 scurest，CC BY 4.0 International。
- 用途：菜园中会沿边缘活动的小动物。

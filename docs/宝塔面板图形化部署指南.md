# 我的菜园：宝塔 13.0.0 最简部署

本版本是一个完整的 Python 项目：FastAPI 同时提供手机网页、3D 菜园、数据接口和 SQLite 数据库。服务器不需要安装 Node，也不需要安装旧版“Python 项目管理器”插件。

部署包：`grow-bt13-sqlite-compatible-20260910.zip`

正式域名：`garden.example.com`

## 一、上传并解压

1. 登录宝塔 13，打开“文件”。
2. 进入已有目录 `/www/wwwroot/grow`，把部署压缩包上传到这个目录。
3. 直接在 `grow` 目录内解压。新版压缩包没有外层文件夹。
4. 解压后 `/www/wwwroot/grow` 内应直接看到 `app`、`static`、`data`、`requirements.txt` 和 `README-先看这个.md`。
5. 在文件管理器中选中 `data` 文件夹，打开“权限”，所有者与用户组选择 `www`，权限填写 `755`。部署包已经附带可直接使用的 `data/grow.db`。

## 二、添加 Python 项目

打开“网站 → Python 项目 → 添加 Python 项目”，按下面填写：

| 宝塔字段 | 填写内容 |
| --- | --- |
| 项目名称 | `grow-garden` |
| Python 环境 | 选择现有的 Python 3.13 环境 |
| 启动方式 | 选择“命令行启动” |
| 项目路径 | `/www/wwwroot/grow` |
| 启动命令 | `python -m uvicorn app.main:app --host 0.0.0.0 --port 8010` |
| 环境变量 | 选择“无” |
| 启动用户 | `www` |
| 安装依赖包 | 选择 `/www/wwwroot/grow/requirements.txt` |

你当前已经有 Python 3.13.15 环境，直接选择它即可。整个过程都在宝塔网页中完成。

点击“确定”。宝塔会创建环境、安装依赖并启动项目。项目状态显示“运行中”后继续下一步。

## 三、绑定域名和 HTTPS

1. 确认域名控制台中 `garden.example.com` 的 A 记录已经指向服务器公网 IP。
2. 在 Python 项目列表打开 `grow-garden` 的“域名管理”，添加 `garden.example.com`。宝塔会自动把域名转发到这个 Python 项目，不需要另外创建 PHP 站点，也不需要手工写反向代理。
3. 打开该项目的“SSL”，申请免费证书。
4. 证书成功后开启“强制 HTTPS”。

## 四、检查是否成功

依次用浏览器打开：

- `https://garden.example.com`：手机管理和 3D 菜园；
- `https://garden.example.com/health`：应显示 `status: ok`；
- `https://garden.example.com/api/docs`：完整接口说明。

数字二维码使用以下固定格式：

`https://garden.example.com/q/001`

把末尾编号改成 `002`、`003` 等即可。在网站“管理 → 数字二维码”中可以绑定、解绑和换绑，不需要重新制作二维码图案。

## 五、数据与备份

数据库文件位置是：

`/www/wwwroot/grow/data/grow.db`

部署包中已包含建好表和 001～004 示例地块的数据库。数据库使用单文件兼容模式，不依赖 `.db-wal` 或 `.db-shm` 文件，便于宝塔识别。后续所有手机操作都会保存到这个文件。

在宝塔中接入数据库：

1. 如果 Python 项目正在运行，先在项目列表点击“停止”。
2. 打开“数据库 → SQLite → 添加数据库”。
3. 数据库文件选择 `/www/wwwroot/grow/data/grow.db`。
4. 添加成功后，再回到 Python 项目点击“启动”。

停止项目只是为了避免宝塔检测时文件正被占用，不会丢失数据。

在宝塔“计划任务”中添加“备份目录”任务，目标选择 `/www/wwwroot/grow/data`，每天备份一次即可。更新网站前也先备份这个目录。

## 六、最常见的三个问题

### 项目启动后显示模块不存在

编辑 Python 项目，确认“安装依赖包”选择的是 `/www/wwwroot/grow/requirements.txt`，然后重新安装依赖。新版文件只包含 `fastapi`、`uvicorn`、`tzdata` 三个模块名，不限制版本。

### 显示 SQLite 只读或不能写入

在宝塔“文件”中重新设置 `data` 文件夹：所有者 `www`、用户组 `www`、权限 `755`，再重启 Python 项目。

### 添加数据库时提示“不是有效的 SQLite 数据库文件”

请确认选择的是 `/www/wwwroot/grow/data/grow.db`，而不是 `grow.db-wal`、`grow.db-shm`、压缩包或文件夹。先停止 Python 项目再添加；新版部署包内的数据库已经过 SQLite 完整性检查。

### 域名显示 502

先看 Python 项目状态是否为“运行中”，再确认启动内容末尾端口是 `8010`，域名绑定的项目也是 `grow-garden`。

## 七、以后更新版本

1. 先在宝塔备份 `/www/wwwroot/grow/data`。
2. 上传新版压缩包并解压到临时目录。
3. 用文件管理器替换 `app`、`static` 和 `requirements.txt`。
4. 不要覆盖或删除原来的 `data` 文件夹。
5. 在 Python 项目中重新安装依赖，然后点击“重启”。

# 我的菜园后端

这是可独立部署的 FastAPI + SQLite 应用。它同时提供：

- 手机端 Three.js 菜园页面；
- 地块和当前种植状态管理；
- 浇水、施肥、除草、病虫害、打药与拍照记录；
- 数字二维码绑定、解绑、换绑与扫码跳转；
- 病虫害问题跟踪；
- 肥料、药剂、种子和工具库存；
- 绍兴市越城区每日天气缓存；
- 地块、作物封面、作物生长照片和物资多图档案的七牛云图片上传；
- SQLite 自动建表与首次示例数据。

菜园页面可以公开查看；新增、编辑、删除、库存、二维码和天气刷新等管理操作需要 `GROW_ADMIN_PIN` 配置的四位数字密码。验证成功后使用 HttpOnly Cookie 保持 30 天，修改 PIN 或 `GROW_ADMIN_SESSION_SECRET` 会让旧会话失效。将 `.env.example` 复制为与 `app/` 同目录的 `.env` 后，程序会自动读取其中配置；系统环境变量优先。

物资可以独立删除或重新新增。删除物资不会删除农事记录，库存流水会保留删除前的物资名称、单位、数量和结存快照；如果删除关联农事记录时物资仍存在，才会执行库存退回。

出入库流水可以单独删除；该操作只删除历史流水，不改变当前库存或关联农事记录。作物详情页可以持续添加带时间和备注的生长照片；物资编辑页可以一次选择多张图片，保存后统一上传，首图显示在库存列表。种子关联仅保存可选的名称快照。图片上传接口为 `/api/v1/media/upload`：原图先发到本后端，最长边超过 2048 像素时等比例缩小，再以无损 WebP 上传到七牛；最终文件严格不超过 2 MB。需要在私有 `.env` 中配置七牛云 AK/SK。

接口说明部署后可在 `/api/docs` 查看。SQLite 默认保存在 `data/grow.db`，使用宝塔兼容的单文件日志模式，可直接在宝塔 SQLite 数据库中添加。升级程序时请保留整个 `data` 文件夹。
